# Geometric Lib (Геометрическая библиотека)

Библиотека Python-модулей для расчёта площади и периметра базовых фигур: круга, прямоугольника, квадрата и треугольника.

## Общее описание решения

Каждая фигура реализована в виде отдельного модуля — `circle.py`, `rectangle.py`, `square.py`, `triangle.py`. В каждом модуле по две функции, отвечающие за расчёт:

- Площадь (`area`)
- Периметр (`perimeter`)

Функции принимают числовые параметры (стороны, радиус, высоту — в зависимости от фигуры) и возвращают результат вычисления. Модули подключаются обычным импортом и используются как подключаемые библиотеки в сторонних Python-проектах.# Geometric Lib (Геометрическая библиотека)

Библиотека Python-модулей для расчёта площади и периметра базовых фигур: круга, прямоугольника, квадрата и треугольника.

## Общее описание решения

Каждая фигура реализована в виде отдельного модуля — `circle.py`, `rectangle.py`, `square.py`, `triangle.py`. В каждом модуле по две функции, отвечающие за расчёт:

- Площадь (`area`)
- Периметр (`perimeter`)

Функции принимают числовые параметры (стороны, радиус, высоту — в зависимости от фигуры) и возвращают результат вычисления. Модули подключаются обычным импортом и используются как подключаемые библиотеки в сторонних Python-проектах.
## Описание функций

### circle.py

#### `area(r)`
Площадь круга: `pi * r²`.

```python
from circle import area

area(2)  # 12.566370614359172
```

#### `perimeter(r)`
Длина окружности: `2 * pi * r`.

```python
from circle import perimeter

perimeter(2)  # 12.566370614359172
```

### rectangle.py

#### `area(a, b)`
Площадь прямоугольника со сторонами `a` и `b`: `a * b`.

```python
from rectangle import area

area(3, 5)  # 15
```

#### `perimeter(a, b)`
Периметр прямоугольника: `2 * (a + b)`.

```python
from rectangle import perimeter

perimeter(3, 5)  # 16
```

### square.py

#### `area(a)`
Площадь квадрата со стороной `a`: `a**2`.

```python
from square import area

area(4)  # 16
```

#### `perimeter(a)`
Периметр квадрата: `4 * a`.

```python
from square import perimeter

perimeter(4)  # 16
```

### triangle.py

#### `area(a, h)`
Площадь треугольника по стороне `a` и высоте `h`, проведённой к этой стороне: `a * h / 2`.

```python
from triangle import area

area(6, 4)  # 12.0
```

#### `perimeter(a, b, c)`
Периметр треугольника по трём сторонам: `a + b + c`.

```python
from triangle import perimeter

perimeter(3, 4, 5)  # 12
```

## Использование нескольких модулей одновременно

Поскольку функции во всех модулях называются одинаково, при совместном импорте нужны псевдонимы:

```python
from circle import area as circle_area
from square import area as square_area

circle_area(2)   # 12.566370614359172
square_area(4)   # 16
```
